What it handles

Use the generated API methods, or drop down to a raw request for endpoints newer than the bundled specification.

Queries and response objects

Generated endpoint groups, response objects that preserve unknown fields, and a schema-aware query builder.

query.where(:Status).equals("Ready")

API version compatibility

Supports Notion API versions 2022-06-28, 2025-09-03, and 2026-03-11.

Request middleware

Retries, rate limiting, timeouts, logging, and instrumentation are included.

Use new endpoints before the next release.

client.request(:get, "/v1/users/me")
